# Enhance accessibility of Markdown files
## Purpose: 
Enhance Accessibility of Markdown Files such as PowerPoint
* Alt Text to Figures
* Add captions to figures

## Resources
In PowerPoint
* Add Speak tool to tool bar
* Review > Check Accessibility
* For ideas for adding alt text to figures, select figure, go to Alt Text, generate alt text for me

For PowerPoint slides stored in Google Drive
 1. Convert the file to Google Slides
* Open the file in Google Drive.
* Select Save as Google Slides.
2. Enable Screen Reader
* SupportThe "Verbalize Selection" option is hidden by default and only appears when screen reader support is turned on in your Google Slides settings.
* Go to Tools > Accessibility settings.
* Check the box for Turn on screen reader support
3. Turn on your device's Screen ReaderThe "Verbalize Selection" feature does not speak text out loud on its own; rather, it sends the selected text to your computer's screen reader program. For you to hear the audio, you must have an active screen reader running in the background.
* ChromeOS: Turn on ChromeVox.
* Windows: Turn on NVDA, JAWS, or Windows Narrator.
* Mac: Turn on Apple VoiceOver.
4. Verbalize your selection
* Once your screen reader is running and the accessibility settings are enabled, you can have Google Slides read specific parts of your presentation
